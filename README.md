# 绒绒星球 v4

一个无需后端的五角色同屏陪伴游戏。本版以暖光房间、横向五角色、生活场景卡片和四项主导航为视觉基线，只保留糯团、桃可、牙牙啾、麦朵、树果五位正式角色。

## 本地运行

必须从仓库根目录启动：

```bash
python -m http.server 8765
```

访问 <http://127.0.0.1:8765/>。

## 角色系统

- 五套独立 SVG 结构与剪影，不复用换色宠物模板。
- 每只 50 条专属台词，共 250 条；按时间、需要、触摸、喂食、玩耍、连续互动、亲密阶段与待机分类。
- Reaction Engine 结合角色、动作、触摸区域、连续次数、最近台词、亲密度和时间选择反应。
- 独立待机权重与 6 个低频角色关系事件。
- `fluffy_planet_v4` 存档保留等级、金币、成就、道具和互动记忆，并从 `fluffy_planet_v2` 安全迁移。

## 部署

纯静态站点，入口为仓库根目录 `index.html`，所有资源使用相对路径，适用于 GitHub Pages 项目子路径。
