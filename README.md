# 绒绒星球 v3

一个无需后端的移动端电子萌宠游戏。宠物会在房间里自由走动、根据性格自主玩耍或休息，并会对身体触摸、家具和多种互动做出不同反应。

v3 包含 8 种宠物、昼夜房间、口渴等六维需求、170 条动态台词、25 件可视化服装、七日签到和 10 项成就。游戏继续使用原有的 `fluffy_planet_v2` 存档键，并会自动迁移旧存档。

## 本地运行

请通过 HTTP 服务器打开网站，不要直接使用 `file://`：

```bash
python -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/>。

## 部署

本站作为纯静态网站部署到 GitHub Pages，入口文件为仓库根目录的 `index.html`。所有站内资源均使用相对路径，可在 GitHub Pages 项目子路径下正常加载。

## 数据说明

游戏进度仅保存在当前浏览器的 `localStorage` 中。清理浏览器网站数据或点击“重新领养”会移除本地存档。
