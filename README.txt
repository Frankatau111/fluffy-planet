绒绒星球 v2 — 电子萌宠网页

打开方式
- 直接双击 index.html 即可运行
- 手机浏览器同样可用
- 不需要后端，所有数据先保存在浏览器 localStorage

v2 新增
- 8 种宠物：奶油柯基、赤柴、布丁猫、银灰猫、草莓兔、焦糖熊、奶茶仓鼠、糯米熊猫
- 更完整的宠物 SVG 造型，而不是简单圆形卡片
- 待机呼吸、眨眼、摇尾巴
- 摸摸、投喂、玩球、梳毛、洗澡、睡觉
- 跳跃、旋转/晃动、吃东西、撒娇、睡觉等动作
- 6 种食物，不同属性变化
- 亲密度、经验、等级、成长阶段
- 今日任务
- 随机事件
- 衣橱系统
- 帽子 / 衣服 / 配饰 3 类穿搭
- 商店与金币系统
- 成长相册 / 宠物档案
- 浏览器本地存档
- 移动端适配
